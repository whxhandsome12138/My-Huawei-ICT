# 智能体

| 文件 | 说明 |
| :-- | :-- |
| `system-prompt.md` | 完整系统提示词，直接贴进 Nexent「模型与提示词 → 系统提示词」 |
| `yaoheng-agent.zip` | **需要你自己导出**（见下），Nexent 的智能体包：配置 + 全部技能 |

## 为什么 zip 不在仓库里

Nexent 导出的 ZIP 里带的是**你那个环境**的配置：模型名、MCP 服务 ID、知识库 ID。
换台机器导入时这些都对不上，导出再提交反而会误导人。

所以仓库只放「人能读懂、能手工复现」的提示词，ZIP 走 Release 附件。

## 自己导出一份

1. Nexent 左侧 → **Agent 仓库 → 我的 Agent** → 找到「腰衡 · 动作评估」
2. 先**发布**一个版本（未发布不能导）。
3. 右上角 **导出** → 选 **ZIP**（含配置 + 所有技能包；选 JSON 只有配置）。
4. 把 zip 放到 `agent/yaoheng-agent.zip`，或直接作为 GitHub Release 的附件。

## 导入到另一套 Nexent

1. Agent 仓库 → **导入** → 上传 zip。
2. 系统会做**依赖预检**，五类依赖逐个确认：

| 依赖 | 会怎样 |
| :-- | :-- |
| 模型 | 需选你自己环境里可用的模型 |
| 知识库 | 跟导入者的权限走，可能为空 |
| **MCP 服务** | **不会自动带过来，必须手动加**（见 `docs/QUICKSTART.md` 第 2 步） |
| Skill | 随 ZIP 自动导入 |
| 协作 Agent | 需手动重新指定 |

3. 名称或变量名冲突时，可选「直接导入（自动加后缀）」或「LLM 重新生成名称」。

导完把 MCP 地址改成本机的，点一次工具列表左边的 ⟳ 复验，看到 5 个工具就算接好。
