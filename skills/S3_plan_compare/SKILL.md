# 用途

回答"这两次比，有没有变化"。工具只做同口径对照和可比性判断，**不下"有没有进步"的结论**。

# 触发条件

用户出现下列意图时，**必须先调 `plan_session`，不能自己拼表**：

- "对比""比较""放在一起"
- "这两次""前后""有没有变化"
- "做个方案""排一下"

# 步骤

1. **收集 sample_id**
   1–5 条，不可重复。少于 1 条或多于 5 条 → 按 `INVALID_ARGUMENT` 处理。
   用户只给了 1 条却说要对比 → 先问要跟哪一条比，或推荐一条。

2. **调 `plan_session(sample_ids=[...])`**

   返回三段，直接对应回答的三段：

   - 可比性提醒（是否同人、同装置、同日期）
   - 并排对照（同口径指标）
   - 可给 / 不可给（工具会明确列出不给处方）

3. **必要时补细节**
   某一条的某个指标需要单独解释 → 对那条调 `assess_exercise`，不要从对照表里反推。

4. **组织回答**
   先讲可比性，再讲数字。顺序不能反——先给差异、再补"其实不可比"，等于误导。

# 输出模板

```
结论：<能比/不能比 + 最值得注意的一处差异>

一、可比性提醒（先看这个）
- 是否同一受试者、同一采集条件：<工具说法>
- 相机竖直轴未标定，跨记录绝对值差异可能来自标定差异
- 以活动范围、上向偏移、次数这类相对量为准更稳妥

二、并排对照（同一工具口径）
| 指标 | 记录 A | 记录 B |
|---|---|---|
| 帧数 / 有效帧占比 | … | … |
| 左侧活动范围 | … | … |
| 左侧上向偏移 | … | … |
| 峰值计数（左/右） | … | … |

三、读法（最多三点）
1. …

四、可以做的与不能做的
- 可以：对照数值、逐条复评、纳入第三条记录做横向对照（不是纵向趋势）
- 不能：诊断、疗效判断、训练处方与剂量、用药建议
```

# 硬规则

- **不得**说"进步了""退步了""改善了""恶化了"。只能说"数值上 A 大于 B"。
- 两条记录若不能确认是同一人同一条件，必须写"不能当作同一人的纵向随访"。
- 重复次数按三档口径讲（等于 5 / 大于 5 / 小于 5），不要一律说"多计 1 次"。
- 对照表只填两条记录**都返回了**的指标。某条缺某项就留空并注明"未返回"，不要用另一条的值去猜，也不要用"两侧""各项"概括。
- **表里每一个数字都必须能在某次工具返回里原样找到**。禁止估算、插值、四舍五入补位、由相邻指标推算，也禁止用另一条记录的数值改写后填入。找不到就写"未返回"。
- 不要输出训练动作、组数、时长——这是处方，不在范围内。要讲"可以怎么用这批数据"，只能讲复评与趋势。

# 失败处理

| 情况 | 做法 |
|---|---|
| `INVALID_ARGUMENT`（重复或数量越界） | 说明 1–5 条且不可重复 |
| 某条 `SAMPLE_NOT_FOUND` | 指出是哪条，其余照常对照，标 `partial` |
| 全部缺参照 | 只做同口径数值对照，不做任何好坏判断 |

# 禁止

- 禁止先给结论再补可比性。
- 禁止把"数值不同"表述成"能力变化"。
- 禁止在用户要"方案"时给出处方式内容，改为给"可比性 + 可复评"。
