# 用途

随访场景要回答的是"这一段训练下来，动作有没有变化"。

难点不在算数，在**分清哪些差异来自人、哪些来自采集条件**。这条流程的价值就是拒绝把后者算进前者。

# 前置

- 只有 Es2。
- 需要受试者标识。当前样本 ID 不含受试者姓名，`sample_id` 也不保证能直接归人 → 若无法确认是同一人，**不要假设**，按"不同人"处理并说明。

# 步骤

1. **取候选记录**
   `list_samples(exercise_id="Es2", limit=20)`，按用户给的时间范围筛选。
   从返回里挑出 2–5 条，标注各自的帧数与质量位。

2. **逐条取评估**
   对每条调 `assess_exercise(sample_id, mode="kinematics")`，记录：质量位、有效帧比、活动范围类特征、上向偏移类特征、峰值计数。

3. **排时间**
   没有明确的采集时间字段时，用 `sample_id` 的出现顺序或用户口述顺序，并在回答里注明"时间顺序依据用户提供"，不要伪造日期。

4. **分组**
   把确认同条件的放一组（可纵向比），条件不明的单独列（只做描述，不参与趋势）。

5. **对照**
   用 `plan_session(sample_ids=[...])` 做同口径对照，取它的可比性提醒。

6. **组织回答**
   先"能说清什么"，再"还不能说清什么"，最后"下一步建议"（建议只能是复评与记录规范，不是训练处方）。

# 输出模板

```
结论：<这段时间能确认的一处变化 / 或"暂时无法确认变化，原因如下">

一、记录清单
| 顺序 | sample_id | 帧数 | 质量 | 可比组 |
|---|---|---|---|---|
| 1 | Es2-… | 1664 | pass | A |
| 2 | Es2-… | 587 | pass | 未知 |

二、同口径对照（仅 A 组内）
| 指标 | 第 1 次 | 第 2 次 | 差异 |
|---|---|---|---|
| 左侧活动范围 | … | … | … |
| 左侧上向偏移 | … | … | … |

三、这次能说清的
- <基于相对量的描述，不涉及好坏>

四、还不能说清的
- 采集条件是否一致未确认，绝对值差异可能来自机位与标定
- 只覆盖 Es2 一个动作，不能代表整体功能

五、下一步
- 建议保持同一设备、同一机位、同一距离复测
- 建议每次记录采集日期与时长，便于后续归组
- 具体训练安排请由治疗师决定
```

# 硬规则

- 用户说"我好点了吗" → 不接这个判断。回答"数据显示哪些量变了，但变化是否代表好转需要治疗师判断"。
- 数字之间不能相减凑"改善幅度"。
- 组数少于 2 条时，说明"单条记录无法看趋势"。
- 时间顺序不确定就写"依据用户提供的顺序"，不要编日期。

# 失败处理

| 情况 | 做法 |
|---|---|
| 只有 1 条可用 | 说明无法看趋势，给单次评估（转 `assess-and-explain`） |
| 各条质量不一 | 质量差的单独列，不并入对照 |
| 无法确认同一受试者 | 明确写"不能当作纵向随访"，只做独立评估 |

# 禁止

- 禁止把"数值变化"表述为"康复效果"。
- 禁止用外推法补缺失记录。
- 禁止在没有日期依据时写出具体日期。
